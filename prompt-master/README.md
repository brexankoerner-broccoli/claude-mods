# Prompt Master

Type a rough prompt, then press **✨ Prompt Master** in the band just above the prompt box (or press `p` while the band has focus). Claude rewrites your draft into a clearer, more complete prompt and puts it back in the box so you can review and edit it before you send it. **Undo** puts your original draft back.

You can also run `/prompt-master <your rough prompt>`.

The rewrite keeps your intent and facts, adds missing structure (goal, context, constraints, output format), and marks clearly missing details with `[placeholders]`. Nothing is sent until you press Enter.
